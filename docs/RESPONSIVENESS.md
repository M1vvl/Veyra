# v1.0.1 响应性修复

Dock 的窗口属性、目录和文件版本读取移至单个后台任务。界面仅提交完成的窗口快照，后台调用阻塞期间保留已有结果，不累积轮询工作任务。窗口关闭或桌面暂停后忽略迟到结果。

控制中心的音量读取与写入移出界面线程。连续写入串行合并，关闭面板后完成最后一次已提交请求。侧栏和控制中心共享单个后台音量读取。

托盘转发到 Explorer 最多等待 40 毫秒，失败后退避 2 秒。uilicd 自己的通知图标注册、消息闪烁格位与点击回调独立处理。对方恢复后允许重新转发。原生开始窗口补充枚举加入数量上限和循环检测。

运行时使用单个低频心跳监测界面。超过两秒时在本机 `%LOCALAPPDATA%\GlassDock\diagnostics.log` 记录停顿、操作类别与恢复，不收集文件名称，不自动上传或强制重启。

## 针对性验证

单文件 EXE 通过 13 项阻塞与恢复检查、28 项真实 Shell 托盘协议检查，另有 12 项托盘布局及闪烁检查通过。阻塞窗口模拟中单次原生消息等待约 40 毫秒，2,000 次重复调用触发退避。真实 Dock 在模拟 Shell 阻塞期间保持 Dispatcher 心跳，关闭后安全忽略后台返回。

```powershell
.\uilicd.exe --responsiveness-probe .\responsiveness.json
.\uilicd.exe --tray-host-probe .\tray-host.json
.\uilicd.exe --sidebar-tray-probe .\sidebar-tray.json
```

上述诊断使用测试进程自有窗口和图标，不改变系统音量、用户收纳或固定项。未重复运行全软件测试。原生 COM、驱动或第三方程序的所有异常无法通过有限测试穷尽；后台调用不被强制终止，心跳日志用于继续定位现场异常。
